Deep dive: open-source leadership

A training program that runs in public

Vets Who Code teaches on GitHub. The entry requirements, the setup guides and the production app are all open repositories, and the people in the program write a large share of them.

The problem

A veteran applying to a coding program has no way to show an employer what they did there, and a program has no way to prove what it teaches, unless the work is visible. Closed course platforms hide both. They also leave graduates with nothing in their GitHub history except tutorial clones.

What it has to do

  • An applicant can start before being accepted, for free, with nothing but a browser and a GitHub account.
  • Work a learner does in the program leaves a public record they can show an employer.
  • Material stays current because the people using it can fix it.

Approach

Prework as the application

Prework is a 40 to 50 hour self-paced course in six modules. An applicant builds a portfolio, deploys it to GitHub Pages and applies with the live URL. The application is proof of work, and the repository has been forked 52 times.

Guides written by the people who needed them

The Windows Dev Guide covers WSL 2, Windows Terminal, Git and the GitHub CLI. It was written by stephanlamoureux, not by me, and it is the most starred repository in the organization. That is the outcome I want from the program: a contributor ships something hundreds of other developers use, under their own name. The API List is a community-curated list of free APIs for people learning JavaScript.

The production app as the classroom

Learners contribute to the vetswhocode.io platform under the same rules as everyone else: conventional commits, type checks, tests and review. I approved 26 merged pull requests from about a dozen outside authors on that repository. A public project catalog lists the software the community has shipped.

A published standard

The Standard is the public bar every person in the program is trained to. It is generated from the curriculum graph: 375 topics, 529 prerequisite links, 8 subjects and 53 domains. The curriculum is validated against 128 skills from Lightcast labor market data across 25 modules.

Key tradeoffs

Open by default

Anyone can copy the material. In return, every learner graduates with a public contribution history, and the program’s claims can be checked by reading the repositories.

Credit goes to the author

The most visible repository in the organization does not have my name in its commit history. A founder who needs every artifact to be theirs ends up with fewer artifacts.

Measurable outcome

  • More than 770 stars and 130 forks across Prework, the Windows Dev Guide and the API List.
  • More than 300 veterans trained since 2014, a 97% job placement rate and more than $20M in collective alumni earnings (internal cohort data, reported by Diginomica, December 2025).
  • Tuition is $0. Vets Who Code is a 501(c)(3) with no income share and no loans.

#VetsWhoCode’s tenacious focus on language and computer science fundamentals over frameworks was invaluable in my career transition from being a Radiology Technician in the US Army to building cloud scale infrastructure at Microsoft.

Jeff Martin, US Army veteran, DevOps Engineer at GitHub

AI collaboration note

The guides and prework are written by people. AI enters the program as a subject and as tooling: learners are taught to use it and to defend what it produces, and the organization’s own agent skills are open source in Hashflag Skills.

What I’d change in v2

  • Write longer reviews. Most of my reviews on community pull requests are short approvals. A written review that explains the reasoning teaches more than a merge does.
  • Add link checking and CI to the guide repositories, which currently have none.
